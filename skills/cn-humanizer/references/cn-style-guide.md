# 中文写作指南——怎么写出人味

消除AI模式只完成了一半。另一半是让文字有个性。没有温度的文字和AI腔一样明显。

## 人话测试

把文字念出来。如果听起来像新闻联播、企业通稿或客服话术，就需要改。好的文字听起来像一个具体的人在说话。

## 有观点

别只陈述事实，对事实有反应。

**没有灵魂的：** 该实验取得了一定成果。部分开发者表示认可，也有人持保留态度。

**有人味的：** 这实验的结果说实话有点意外。Twitter上吵翻了，一半人觉得是突破，一半人说数据有水分。我倾向于后者——sample size才200。

## 变节奏

长短交替。碎句也行。然后来一句绕两个弯的长句让读者跟着你的思路走一走。再短一句收住。

**节拍器式：** 这个工具很好用。它处理数据很快。用户评价很高。界面也很简洁。

**有变化的：** 这工具确实好用。快，很快——跟我们之前那个手动流程比简直是降维打击。用户好像挺满意的，不过我怀疑一半人根本没试过高级功能。

## 承认矛盾

真人会有复杂的感受。"这东西挺强的但也挺吓人的"比一味夸或一味贬都真实。

**AI式扁平：** 这是一个创新的解决方案，有效解决了行业痛点。

**有人味的：** 技术上确实聪明，但我用着有点不安。故障模式还不太清楚，万一出事谁负责？

## 用第一人称

"我"不丢人。

- "我试了一下..."
- "我一直觉得..."
- "据我了解..."
- "我碰到过一个情况..."
- "说实话我不太确定..."

## 留一些不完美

太工整的结构感觉像算法生成的。跑个题、插句闲话、说到一半拐个弯，这些都是人味。不是每篇都需要，但偶尔来一下能让文字活起来。

## 说具体的

"很重要"什么都没说。"杭州，常住人口1237万，去年GDP18753亿"什么都说了。

用具体细节替代空洞形容：
- "重要城市" → "杭州，阿里总部在这儿，去年GDP全国第八"
- "近期研究" → "斯坦福今年3月发了一篇，调查了500个开发者"
- "显著增长" → "Q3营收涨了34%"
- "很多用户" → "日活230万"

## 用简单动词

| 别用 | 用 |
|-----|---|
| 作为...的存在 | 是 |
| 具备...的能力 | 能、会 |
| 呈现出...的特征 | 像、有 |
| 得到了...的提升 | 提高了、变好了 |
| 受到了...的关注 | 有人关注、火了 |
| 实现了...的突破 | 突破了、做到了 |

## 删废话

每个字都要值回它占的位置。能删不改就删。

| 删掉 | 保留 |
|-----|------|
| 在...的过程中，我们... | 我们... |
| 对于...而言，它是... | 它是... |
| 从某种意义上来说 | （删掉） |
| 值得一提的是 | （删掉，直接说） |
| 不难发现 | （删掉，直接说发现了什么） |
| 正如我们所知道的那样 | （删掉） |

## 修饰语一个就够

"可能也许大概" = "可能"。挑一个最准确的，别叠加。

**叠加：** 可以说在某种程度上可能会产生一定的积极影响。

**直接：** 可能有帮助。

## 结尾说真话

别够鸡汤，说个事实、提个问题、或者就停了。

**鸡汤：** 未来可期，让我们拭目以待！

**具体：** 他们明年计划再开两家店。能不能活下来，看Q4的数据。

**或者直接停：** 他们明年计划再开两家店。

## 格式建议

- 标题不要每个词都大写（中文没这个问题，但注意不要加多余的书名号和引号）
- 正文里少用加粗——让文字本身传达重点
- 别用emoji装饰专业文章
- 列表项保持简短、并列
- 少用"——"（中文破折号），多用逗号和句号
- 别搞"**主题：** 解释主题"这种列表格式
